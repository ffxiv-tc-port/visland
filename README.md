# visland

無人島開拓全方位自動化插件。

## 功能

- **採集**：錄製／播放採集路線，自動移動並採集
- **農場**：自動收成、可設定自動託管與淘汰作物
- **牧場**：自動收取家畜產物
- **穀倉**：自動收取、自動重新分配島民工作
- **產物出口**：自動賣出超過庫存門檻的商品
- **工坊**：排程解算器（依可用時段自動排出高產值的工坊排班），支援匯入行事曆／手動排程
- 素材帳本：統計各項島嶼素材的產量與去向
- 採集流程可選擇自動觸發抽取靈魂結晶、修理裝備等一般行動
- 覆寫攝影機／自動反 AFK／輔助移動等通用小工具
- 與 AutoRetainer、vnavmesh 整合（IPC）

## 使用

- `/visland` 開啟主視窗；各分頁功能也會在對應建築物旁的原生介面浮現快速設定

## 安裝

在 Dalamud 設定的「自訂插件庫」加入
`https://raw.githubusercontent.com/ffxiv-tc-port/DalamudPluginsTC/main/repo.json` 並啟用，
再從插件列表安裝。
