# visland

[visland](https://github.com/awgil/ffxiv_visland) 的台服移植版。無人島開拓與採集路線的自動化插件。

## 功能

- **採集路線**：錄製／播放採集路線，自動移動並採集；可跨區域傳送、可設定路線用的料理，路線中可順便精製魔晶石、修理裝備、精選收藏品
- **耕地**：自動領取作物、一鍵全部開始／結束託管，並標出開拓工坊排程還需要的量
- **牧場**：自動領取畜牧產物
- **囤貨倉庫**：自動領取、自動變更探索目的地；依工坊排程的需求替各探索地點排序
- **產品交易**：自動出口超過庫存門檻的素材，可選擇保留工坊排程還需要的量
- **開拓工坊**：排程解算器；載入 Overseas Casuals 封存推薦排程、手動排程、貓耳小員請求整合
- **缺料總表**：對照工坊排程的需求、背包庫存與囤貨倉庫／耕地／牧場正在產出的量，列出還缺哪些素材（純顯示）
- **自動化分頁**：在主視窗集中設定囤貨倉庫、耕地、牧場、產品交易的自動化選項（實際按鈕仍要站在對應建築前操作，或用下面的一鍵巡島走過去）
- **一鍵巡島**：人已經在無人島上時，依序走到勾選的小員旁邊、說話並打開管理視窗，視窗裡的事交給上面的自動化設定；處理不完的視窗會留給你，關掉之後接著走下一站。只有按下「開始巡島」或 `/visland tour` 才會動，載入、進區、登入都不會自己開始；巡島期間會暫停 YesAlready 與 TextAdvance（需要 vnavmesh）
- 跑路線時自動控制移動與鏡頭、避免閒置被登出
- 跑路線時可選擇在僱員／潛水艇完成時暫停，交給 AutoRetainer 處理完再繼續
- 提供 IPC（`visland.StartRoute`、`visland.StopRoute` 等）給其他插件啟動／停止路線，另有只能停止的急停端點 `visland.StopAll`

## 使用

- `/visland` 開啟主視窗；各分頁功能也會在對應建築物旁的原生介面浮現快速設定
- `/visland exec <路線名>`：連續執行指定路線；`execonce` 只跑一次；`exectemp`／`exectemponce` 執行未儲存的路線（base64）
- `/visland stop`／`pause`／`resume`：停止／暫停／繼續目前的路線（`stop` 也會停下巡島）
- `/visland tour`：開始一鍵巡島
- `/visland moveto <X> <Y> <Z>`：移動到指定座標；`movedir <X> <Y> <Z>`：以角色面向為基準移動指定距離

## 台服版的修改

- 新增「缺料總表」分頁與「自動化」分頁
- 新增一鍵巡島（手動開始，說明見上）
- 新增工坊「休息日」分頁：兩週合計 0～4 天自由設定（原生介面固定每週兩天），已開始或已結束的生產日不能改
- 封存排程只涵蓋 5 個生產日時，可用遊戲的受歡迎度與需求資料在本機補上其餘生產日；貓耳小員請求可設定盡量排在最早的生產日
- 囤貨倉庫與耕地顯示工坊排程的需求；產品交易可保留工坊還需要的量
- 採集路線可設定「所有路徑點都用 vnavmesh 尋路」繞過障礙物（預設開；沒有 vnavmesh 或尋路失敗時那一段退回直線），會上坐騎的路段短於設定距離（預設 20 米）時直接用走的
- 採集路線清單搜尋時自動展開有命中的群組並標出命中筆數，清掉搜尋後還原原本的展開狀態
- 路線跑完或因錯誤停下時，可請塔塔露念一句（需安裝 TataruPraise）
- 「騎乘（不飛行）」航點改成邊走邊上坐騎，不再每段路先停下來召喚
- 自動採集遇到捕魚錯誤訊息時確實停下
- 路線停止、暫停或換點時只停自己送出的 vnavmesh 路徑，不會取消其他插件的導航
- 設定檔有一部分讀不懂時先備份原檔，不再連帶清掉其餘設定與全部採集路線；存檔改成先寫暫存檔再取代
- 不對正在關閉中的原生視窗重複按下，其他插件的 IPC 呼叫改在遊戲主執行緒上執行，降低崩潰風險
- 多處降低記憶體用量
- 介面繁體中文化（無人島設施名稱依台服現行譯名）

## 安裝

1. 在遊戲內輸入 `/xlsettings` 開啟「Dalamud 設定」，到「試驗性功能」分頁的「第三方插件倉庫」加入
   `https://raw.githubusercontent.com/ffxiv-tc-port/DalamudPluginsTC/main/repo.json`
   勾選啟用後儲存。
2. 輸入 `/xlplugins` 開啟「插件管理員」，搜尋「Visland」安裝。

同一個插件只裝這裡的版本，不要同時安裝上游（國際服）版本。

## 需要搭配的插件

- 選用：[vnavmesh](https://github.com/ffxiv-tc-port/vnavmesh)（採集路線尋路、一鍵巡島）、[AutoRetainer](https://github.com/ffxiv-tc-port/AutoRetainer)（路線中處理僱員／潛水艇）、[TataruPraise](https://github.com/ffxiv-tc-port/TataruPraise)（塔塔露語音）
